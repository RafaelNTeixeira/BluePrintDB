# Screenshots

Drop your screenshots in this folder using the exact filenames below —
the project's root `README.md` already references them.

| Filename                     | What to capture                                                              |
|-------------------------------|-------------------------------------------------------------------------------|
| `hero.png`                   | Wide shot of the full canvas with a few connected tables — this is the first image people see. |
| `table-node.png`             | Close-up of one table node: name, a few columns, the PK/UQ/N? badges, the data-type dropdown open. |
| `relationship-picker.png`    | An edge selected/clicked with the 1:1 / 1:N / N:N picker menu open.          |
| `export-panel.png`           | The export panel open, ideally on the SQL or Prisma tab with real generated code visible. |

Tips for good screenshots:
- Use a real, slightly-populated schema (3–5 tables) rather than one empty table — it reads much better.
- PNG, ~1600px wide is plenty; you don't need retina-resolution files.
- Dark backgrounds (the app's own blueprint theme) will look best without extra cropping/padding.
